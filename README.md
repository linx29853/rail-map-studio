# 沿线 · 日式线路图制作

独立的日式车内线路图生成器。无需安装依赖，直接在浏览器打开 `dist/index.html` 即可使用。

## 功能

- 每行输入一个站名，可使用 `站名 | English name` 添加英文。
- 普通默认各站停车，自定义快速、急行、特急等列车级别及停站。
- 斜排站名、方框站号、统一可选线路颜色。
- 多级停靠采用带描边的白色长条；不连续的停靠级别分别标记。
- 支持换乘线路和站间距调整。
- 导出 SVG 或两倍分辨率 PNG。

## 使用

1. 打开 `dist/index.html`。
2. 填写线路及站名，点击“应用站名”。
3. 在停站表中勾选停站，填写换乘线路。
4. 导出线路图。

当前编辑内容仅保留在页面内；刷新或关闭前请导出图片。

## 开发

安装 Node.js 后，可执行 `node serve.cjs`，访问 `http://127.0.0.1:8769`。
执行 `node check.cjs` 检查内嵌 JavaScript 语法。

美术排版参考日本铁路停站指南，未包含铁路公司的标志或官方图面素材。
